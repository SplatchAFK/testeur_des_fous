Задание             : ft_memrchr
Ожидаемые файлы     : ft_memrchr.c
Разрешённые функции : malloc, free, write, твоя libft
--------------------------------------------------------------

Найди ПОСЛЕДНИЙ байт c (как unsigned char) в первых n байтах s, или NULL.

Твоя функция должна иметь такой прототип:

void	*ft_memrchr(const void *s, int c, size_t n);

Тема: цикл назад с size_t
Норма обязательна. Вспомогательные функции должны быть static.
