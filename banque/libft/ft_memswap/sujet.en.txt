Assignment name    : ft_memswap
Expected files     : ft_memswap.c
Allowed functions  : malloc, free, write, ta libft
--------------------------------------------------------------

Swap the first n bytes of a and b. Works for any type.

Your function must have this prototype:

void	ft_memswap(void *a, void *b, size_t n);

Notion : void * et octets
Norme obligatoire. Les fonctions d'aide doivent être static.
