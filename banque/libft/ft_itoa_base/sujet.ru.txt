Задание             : ft_itoa_base
Ожидаемые файлы     : ft_itoa_base.c
Разрешённые функции : malloc, free, write, твоя libft
--------------------------------------------------------------

Запиши n в системе base в новую строку. Обработай LONG_MIN. NULL при неверной системе счисления.

Твоя функция должна иметь такой прототип:

char	*ft_itoa_base(long n, const char *base);

Тема: LONG_MIN, подсчёт цифр, точный malloc
Норма обязательна. Вспомогательные функции должны быть static.
