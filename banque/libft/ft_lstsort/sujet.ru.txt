Задание             : ft_lstsort
Ожидаемые файлы     : ft_lstsort.c
Разрешённые функции : malloc, free, write, your libft
--------------------------------------------------------------

Отсортируй список по возрастанию согласно cmp.

Твоя функция должна иметь такой прототип:

void	ft_lstsort(t_list **lst, int (*cmp)(const void *, const void *));

Тема: сортировка связного списка
Норма обязательна. Вспомогательные функции должны быть static.
