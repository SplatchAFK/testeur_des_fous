Assignment name    : ft_sort_strs
Expected files     : ft_sort_strs.c
Allowed functions  : malloc, free, write, your libft
--------------------------------------------------------------

Sort a NULL-terminated array in place using cmp. Swap pointers only.

Your function must have this prototype:

void	ft_sort_strs(char **tab, int (*cmp)(const char *, const char *));

Concept: function pointers and sorting
The Norm is mandatory. Helper functions must be static.
