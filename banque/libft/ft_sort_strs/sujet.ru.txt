Задание             : ft_sort_strs
Ожидаемые файлы     : ft_sort_strs.c
Разрешённые функции : malloc, free, write, твоя libft
--------------------------------------------------------------

Отсортируй на месте массив, оканчивающийся NULL, с помощью cmp. Меняй местами только указатели.

Твоя функция должна иметь такой прототип:

void	ft_sort_strs(char **tab, int (*cmp)(const char *, const char *));

Тема: указатели на функции и сортировка
Норма обязательна. Вспомогательные функции должны быть static.
