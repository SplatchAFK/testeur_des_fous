Assignment name    : ft_putnbr_base_fd
Expected files     : ft_putnbr_base_fd.c
Allowed functions  : malloc, free, write, your libft
--------------------------------------------------------------

Write n in base on fd. Invalid base writes nothing. Handle LONG_MIN.

Your function must have this prototype:

void	ft_putnbr_base_fd(long n, const char *base, int fd);

Concept: recursion and write
The Norm is mandatory. Helper functions must be static.
