Задание             : ft_putnbr_base_fd
Ожидаемые файлы     : ft_putnbr_base_fd.c
Разрешённые функции : malloc, free, write, your libft
--------------------------------------------------------------

Запиши n в системе base в fd. Неверная система счисления ничего не пишет. Обработай LONG_MIN.

Твоя функция должна иметь такой прототип:

void	ft_putnbr_base_fd(long n, const char *base, int fd);

Тема: рекурсия и write
Норма обязательна. Вспомогательные функции должны быть static.
