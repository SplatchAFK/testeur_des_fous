Assignment name    : ft_lstremove_if
Expected files     : ft_lstremove_if.c
Allowed functions  : malloc, free, write, your libft
--------------------------------------------------------------

Remove every node where cmp(content, ref) == 0 (del then free).

Your function must have this prototype:

void	ft_lstremove_if(t_list **lst, const void *ref,
			int (*cmp)(const void *, const void *), void (*del)(void *));

Concept: removing while traversing, t_list **
