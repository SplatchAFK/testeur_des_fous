Задание             : ft_putnbr_count
Ожидаемые файлы     : ft_putnbr_count.c
Разрешённые функции : write, malloc, free, va_start, va_arg, va_copy, va_end
--------------------------------------------------------------

Запиши n в десятичной системе (включая INT_MIN, без неопределённого поведения). Верни число записанных символов.

Твоя функция должна иметь такой прототип:

int	ft_putnbr_count(int n);

Тема: INT_MIN без переполнения
Норма обязательна. Здесь без libft.
