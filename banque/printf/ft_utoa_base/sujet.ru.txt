Задание             : ft_utoa_base
Ожидаемые файлы     : ft_utoa_base.c
Разрешённые функции : write, malloc, free, va_start, va_arg, va_copy, va_end
--------------------------------------------------------------

Верни n, записанное в системе base, в строке, выделенной точно по размеру. NULL, если malloc не удался.

Твоя функция должна иметь такой прототип:

char	*ft_utoa_base(unsigned long n, const char *base);

Тема: malloc точного размера
Норма обязательна. Здесь без libft.
