Exercício           : ft_putstr_count
Ficheiros esperados : ft_putstr_count.c
Funções permitidas  : write, malloc, free, va_start, va_arg, va_copy, va_end
--------------------------------------------------------------

Escreve s. Se s for NULL, escreve "(null)" como o printf em Linux. Devolve o número de bytes escritos, -1 se write falhar.

A tua função deve ter este protótipo:

int	ft_putstr_count(char *s);

Conceito: string NULL
A Norma é obrigatória. Sem libft aqui.
