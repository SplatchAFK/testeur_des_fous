Exercício           : ft_dprintf_mini
Ficheiros esperados : ft_dprintf_mini.c
Funções permitidas  : write, malloc, free, va_start, va_arg, va_copy, va_end
--------------------------------------------------------------

Como dprintf só com %c, %s e %d: escreve no fd. Devolve o número de bytes escritos, -1 se write falhar.

A tua função deve ter este protótipo:

int	ft_dprintf_mini(int fd, const char *fmt, ...);

Conceito: dprintf
A Norma é obrigatória. Sem libft aqui.
