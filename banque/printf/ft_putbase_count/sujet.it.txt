Scrivi n nella base data (base = "0123456789abcdef" per esempio). Restituisci il numero di caratteri scritti.

La tua funzione deve avere questo prototipo:

int	ft_putbase_count(unsigned long n, char *base);

Concetto: conversione di base
La Norma è obbligatoria. Niente libft qui.
