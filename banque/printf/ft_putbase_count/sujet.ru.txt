Задание             : ft_putbase_count
Ожидаемые файлы     : ft_putbase_count.c
Разрешённые функции : write, malloc, free, va_start, va_arg, va_copy, va_end
--------------------------------------------------------------

Запиши n в заданной системе (например, base = "0123456789abcdef"). Верни число записанных символов.

Твоя функция должна иметь такой прототип:

int	ft_putbase_count(unsigned long n, char *base);

Тема: перевод между системами счисления
Норма обязательна. Здесь без libft.
