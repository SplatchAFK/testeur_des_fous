Assignment name    : ft_strspn
Expected files     : ft_strspn.c
Allowed functions  : none
--------------------------------------------------------------

Write a function that returns the length of the longest start of s made
only of characters of accept, like strspn (man strspn).

You may include <stddef.h> for size_t.

Your function must have this prototype:

size_t	ft_strspn(const char *s, const char *accept);

The tester calls it from its own main: do not submit one.
