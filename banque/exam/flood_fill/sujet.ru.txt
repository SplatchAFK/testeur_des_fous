Задание             : flood_fill
Ожидаемые файлы     : flood_fill.c, t_point.h
Разрешённые функции : нет
--------------------------------------------------------------

Напиши функцию, которая "заливает" область двумерного массива символов.

В tab size.y строк и size.x столбцов. Область начинается в клетке begin
(столбец begin.x, строка begin.y) и включает каждую клетку с тем же
символом, до которой можно дойти, двигаясь по горизонтали или по
вертикали, но никогда по диагонали. Каждая клетка области заменяется на
'F'.

Сдай также файл t_point.h, в котором объявлено:

typedef struct  s_point
{
    int         x;
    int         y;
}               t_point;

Твоя функция должна иметь такой прототип:

void	flood_fill(char **tab, t_point size, t_point begin);

Тестер вызывает её из своего main: не сдавай свой.
