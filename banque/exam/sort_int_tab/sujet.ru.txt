Задание             : sort_int_tab
Ожидаемые файлы     : sort_int_tab.c
Разрешённые функции : нет
--------------------------------------------------------------

Напиши функцию, которая сортирует size целых чисел массива tab по
возрастанию, на месте. Повторы сохраняются.

Твоя функция должна иметь такой прототип:

void	sort_int_tab(int *tab, unsigned int size);

Тестер вызывает её из своего main: не сдавай свой.
