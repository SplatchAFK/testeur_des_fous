Assignment name    : sort_int_tab
Expected files     : sort_int_tab.c
Allowed functions  : none
--------------------------------------------------------------

Write a function that sorts the size integers of the array tab in
ascending order, in place. Duplicates are kept.

Your function must have this prototype:

void	sort_int_tab(int *tab, unsigned int size);

The tester calls it from its own main: do not submit one.
