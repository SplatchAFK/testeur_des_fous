Exercício           : rev_print
Ficheiros esperados : rev_print.c
Funções permitidas  : write
--------------------------------------------------------------

Escreve um programa que recebe uma string e a mostra ao contrário, seguida
de uma quebra de linha.

Se o programa não receber exatamente um argumento, só mostra uma quebra de
linha.

Exemplos:

$> ./rev_print "kayak" | cat -e
kayak$
$> ./rev_print "Le Testeur" | cat -e
ruetseT eL$
$> ./rev_print | cat -e
$
$>
