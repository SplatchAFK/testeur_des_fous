Assignment name    : rostring
Expected files     : rostring.c
Allowed functions  : write, malloc, free
--------------------------------------------------------------

Write a program that takes a string and displays it with its first word
moved to the end, followed by a newline. Words are separated by a single
space in the output, with no space at the start or the end.

A word is a run of characters delimited by spaces or tabs.

If the program receives several arguments, it only handles the first one.
Without arguments, it only displays a newline.

Examples:

$> ./rostring "le testeur des fous" | cat -e
testeur des fous le$
$> ./rostring "  Marvin   monte la tour  " | cat -e
monte la tour Marvin$
$> ./rostring "unseul" | cat -e
unseul$
$> ./rostring | cat -e
$
$>
