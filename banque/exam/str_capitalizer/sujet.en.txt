Assignment name    : str_capitalizer
Expected files     : str_capitalizer.c
Allowed functions  : write
--------------------------------------------------------------

Write a program that takes one or several strings and, for each one, puts
the first letter of every word in uppercase and every other letter in
lowercase, then displays the result followed by a newline.

A word is a run of characters delimited by spaces, tabs, or by the start
and the end of the string. If the first character of a word is not a
letter, it is unchanged.

Without arguments, the program only displays a newline.

Examples:

$> ./str_capitalizer "le TESTEUR des fous" | cat -e
Le Testeur Des Fous$
$> ./str_capitalizer "une PHRASE " "Deux Phrases	avec tab" | cat -e
Une Phrase $
Deux Phrases^IAvec Tab$
$> ./str_capitalizer | cat -e
$
$>
