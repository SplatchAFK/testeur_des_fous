Задание             : ft_rrange
Ожидаемые файлы     : ft_rrange.c
Разрешённые функции : malloc
--------------------------------------------------------------

Напиши функцию, которая выделяет через malloc массив целых чисел,
заполняет его последовательными значениями от end до start, включая оба, и
возвращает этот массив.

Массив всегда начинается с end.

Например: (1, 3) даёт 3, 2, 1; (-1, 2) даёт 2, 1, 0, -1; (0, -3) даёт -3,
-2, -1, 0.

Твоя функция должна иметь такой прототип:

int	*ft_rrange(int start, int end);

Тестер вызывает её из своего main: не сдавай свой.
