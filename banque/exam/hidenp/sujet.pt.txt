Exercício           : hidenp
Ficheiros esperados : hidenp.c
Funções permitidas  : write
--------------------------------------------------------------

Escreve um programa que recebe duas strings e mostra 1 se cada carácter da
primeira se encontrar na segunda, pela mesma ordem, e 0 caso contrário,
seguido de uma quebra de linha. Uma primeira string vazia está sempre
escondida.

Se o programa não receber exatamente dois argumentos, só mostra uma quebra
de linha.

Exemplos:

$> ./hidenp "fgex.;" "tyf34gdgf;'ektufjhgdgex.;.;rtjynur6" | cat -e
1$
$> ./hidenp "abc" "2altrb53c.sse" | cat -e
1$
$> ./hidenp "abc" "btarc" | cat -e
0$
$> ./hidenp | cat -e
$
$>
