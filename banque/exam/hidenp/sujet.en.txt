Assignment name    : hidenp
Expected files     : hidenp.c
Allowed functions  : write
--------------------------------------------------------------

Write a program that takes two strings and displays 1 if every character
of the first one can be found in the second one, in the same order, and 0
otherwise, followed by a newline. An empty first string is always hidden.

If the program does not receive exactly two arguments, it only displays a
newline.

Examples:

$> ./hidenp "fgex.;" "tyf34gdgf;'ektufjhgdgex.;.;rtjynur6" | cat -e
1$
$> ./hidenp "abc" "2altrb53c.sse" | cat -e
1$
$> ./hidenp "abc" "btarc" | cat -e
0$
$> ./hidenp | cat -e
$
$>
