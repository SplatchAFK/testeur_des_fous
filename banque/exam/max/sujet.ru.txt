Задание             : max
Ожидаемые файлы     : max.c
Разрешённые функции : нет
--------------------------------------------------------------

Напиши функцию, которая возвращает наибольшее из len целых чисел массива
tab. Если len равно 0, она возвращает 0.

Твоя функция должна иметь такой прототип:

int	max(int *tab, unsigned int len);

Тестер вызывает её из своего main: не сдавай свой.
