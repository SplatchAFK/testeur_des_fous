Assignment name    : print_hex
Expected files     : print_hex.c
Allowed functions  : write
--------------------------------------------------------------

Write a program that takes a positive integer written in base 10 and
displays it in base 16, in lowercase, followed by a newline.

If the program does not receive exactly one argument, it only displays a
newline.

Examples:

$> ./print_hex "10" | cat -e
a$
$> ./print_hex "255" | cat -e
ff$
$> ./print_hex "5156454" | cat -e
4eae66$
$> ./print_hex | cat -e
$
$>
