Assignment name    : ft_strcspn
Expected files     : ft_strcspn.c
Allowed functions  : none
--------------------------------------------------------------

Write a function that returns the length of the longest start of s that
holds no character of reject, like strcspn (man strcspn).

You may include <stddef.h> for size_t.

Your function must have this prototype:

size_t	ft_strcspn(const char *s, const char *reject);

The tester calls it from its own main: do not submit one.
