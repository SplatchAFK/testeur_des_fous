Задание             : sort_list
Ожидаемые файлы     : sort_list.c, list.h
Разрешённые функции : нет
--------------------------------------------------------------

Напиши функцию, которая сортирует список lst с помощью функции cmp и
возвращает указатель на первый элемент отсортированного списка.

cmp(a, b) возвращает ненулевое значение, когда a и b стоят в правильном
порядке, и 0 в противном случае. Например, для сортировки по возрастанию:

int ascending(int a, int b)
{
    return (a <= b);
}

Сдай также файл list.h, в котором объявлено:

typedef struct s_list t_list;

struct s_list
{
    int     data;
    t_list  *next;
};

Твоя функция должна иметь такой прототип:

t_list	*sort_list(t_list *lst, int (*cmp)(int, int));

Тестер вызывает её из своего main: не сдавай свой.
