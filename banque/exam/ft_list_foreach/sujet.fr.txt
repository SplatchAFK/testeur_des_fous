Exercice           : ft_list_foreach
Fichiers attendus  : ft_list_foreach.c, ft_list.h
Fonctions permises : aucune
--------------------------------------------------------------

Écris une fonction qui applique la fonction f à la donnée (data) de chaque
élément de la liste qui commence à begin_list, dans l'ordre de la liste.

Rends aussi le fichier ft_list.h, qui déclare la structure suivante :

typedef struct    s_list
{
    struct s_list *next;
    void          *data;
}                 t_list;

Ta fonction doit avoir ce prototype :

void	ft_list_foreach(t_list *begin_list, void (*f)(void *));

Le testeur l'appelle avec son propre main : n'en rends pas.
