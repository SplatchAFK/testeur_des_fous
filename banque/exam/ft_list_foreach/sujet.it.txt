File attesi         : ft_list_foreach.c, ft_list.h
Funzioni consentite : nessuna
--------------------------------------------------------------

Scrivi una funzione che applica la funzione f ai dati di ogni elemento
della lista che inizia da begin_list, nell'ordine della lista.

Consegna anche il file ft_list.h, che dichiara la seguente struttura:

typedef struct    s_list
{
    struct s_list *next;
    void          *data;
}                 t_list;

La tua funzione deve avere questo prototipo:

void	ft_list_foreach(t_list *begin_list, void (*f)(void *));

Il tester la chiama dal proprio main: non consegnarne uno.
