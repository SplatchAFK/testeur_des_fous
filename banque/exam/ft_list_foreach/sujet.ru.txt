Задание             : ft_list_foreach
Ожидаемые файлы     : ft_list_foreach.c, ft_list.h
Разрешённые функции : нет
--------------------------------------------------------------

Напиши функцию, которая применяет функцию f к данным каждого элемента
списка, начинающегося с begin_list, в порядке списка.

Сдай также файл ft_list.h, в котором объявлена следующая структура:

typedef struct    s_list
{
    struct s_list *next;
    void          *data;
}                 t_list;

Твоя функция должна иметь такой прототип:

void	ft_list_foreach(t_list *begin_list, void (*f)(void *));

Тестер вызывает её из своего main: не сдавай свой.
