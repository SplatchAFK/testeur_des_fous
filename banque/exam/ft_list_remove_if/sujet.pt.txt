Exercício           : ft_list_remove_if
Ficheiros esperados : ft_list_remove_if.c, ft_list.h
Funções permitidas  : free
--------------------------------------------------------------

Escreve uma função que remove da lista que começa em *begin_list todos os
elementos cujos dados são "iguais" a data_ref, e liberta esses elementos
com free.

Um elemento é igual quando cmp(element->data, data_ref) devolve 0. A
função não liberta os dados em si. *begin_list tem de continuar correto,
mesmo quando o primeiro elemento é removido.

Entrega também o ficheiro ft_list.h, que declara a seguinte estrutura:

typedef struct    s_list
{
    struct s_list *next;
    void          *data;
}                 t_list;

A tua função deve ter este protótipo:

void	ft_list_remove_if(t_list **begin_list, void *data_ref, int (*cmp)());

O tester chama-a a partir do seu próprio main: não entregues nenhum.
