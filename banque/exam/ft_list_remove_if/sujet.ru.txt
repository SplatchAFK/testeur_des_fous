Задание             : ft_list_remove_if
Ожидаемые файлы     : ft_list_remove_if.c, ft_list.h
Разрешённые функции : free
--------------------------------------------------------------

Напиши функцию, которая удаляет из списка, начинающегося с *begin_list,
каждый элемент, данные которого "равны" data_ref, и освобождает эти
элементы через free.

Элемент равен, когда cmp(element->data, data_ref) возвращает 0. Функция не
освобождает сами данные. *begin_list должен оставаться верным, даже когда
удаляется первый элемент.

Сдай также файл ft_list.h, в котором объявлена следующая структура:

typedef struct    s_list
{
    struct s_list *next;
    void          *data;
}                 t_list;

Твоя функция должна иметь такой прототип:

void	ft_list_remove_if(t_list **begin_list, void *data_ref, int (*cmp)());

Тестер вызывает её из своего main: не сдавай свой.
