Esercizio           : ft_list_size
File attesi         : ft_list_size.c, ft_list.h
Funzioni consentite : nessuna
--------------------------------------------------------------

Scrivi una funzione che restituisce il numero di elementi della lista
concatenata che inizia da begin_list.

Consegna anche il file ft_list.h, che dichiara la seguente struttura:

typedef struct    s_list
{
    struct s_list *next;
    void          *data;
}                 t_list;

La tua funzione deve avere questo prototipo:

int	ft_list_size(t_list *begin_list);

Il tester la chiama dal proprio main: non consegnarne uno.
