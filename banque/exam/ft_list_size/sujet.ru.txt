Задание             : ft_list_size
Ожидаемые файлы     : ft_list_size.c, ft_list.h
Разрешённые функции : нет
--------------------------------------------------------------

Напиши функцию, которая возвращает число элементов связного списка,
начинающегося с begin_list.

Сдай также файл ft_list.h, в котором объявлена следующая структура:

typedef struct    s_list
{
    struct s_list *next;
    void          *data;
}                 t_list;

Твоя функция должна иметь такой прототип:

int	ft_list_size(t_list *begin_list);

Тестер вызывает её из своего main: не сдавай свой.
