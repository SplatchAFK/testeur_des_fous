Esercizio           : ft_range
File attesi         : ft_range.c
Funzioni consentite : malloc
--------------------------------------------------------------

Scrivi una funzione che alloca con malloc un array di interi, lo riempie
con i valori consecutivi che vanno da start a end, entrambi inclusi, e
restituisce questo array.

L'array inizia sempre con start. Se start è maggiore di end, i valori
scendono.

Per esempio: (1, 3) dà 1, 2, 3; (-1, 2) dà -1, 0, 1, 2; (0, -3) dà 0, -1,
-2, -3.

La tua funzione deve avere questo prototipo:

int	*ft_range(int start, int end);

Il tester la chiama dal proprio main: non consegnarne uno.
