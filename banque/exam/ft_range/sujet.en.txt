Assignment name    : ft_range
Expected files     : ft_range.c
Allowed functions  : malloc
--------------------------------------------------------------

Write a function that allocates with malloc an array of integers, fills it
with the consecutive values going from start to end, both included, and
returns that array.

The array always starts with start. If start is greater than end, the
values go down.

For example: (1, 3) gives 1, 2, 3; (-1, 2) gives -1, 0, 1, 2;
(0, -3) gives 0, -1, -2, -3.

Your function must have this prototype:

int	*ft_range(int start, int end);

The tester calls it from its own main: do not submit one.
