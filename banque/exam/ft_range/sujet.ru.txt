Задание             : ft_range
Ожидаемые файлы     : ft_range.c
Разрешённые функции : malloc
--------------------------------------------------------------

Напиши функцию, которая выделяет через malloc массив целых чисел,
заполняет его последовательными значениями от start до end, включая оба, и
возвращает этот массив.

Массив всегда начинается со start. Если start больше end, значения
убывают.

Например: (1, 3) даёт 1, 2, 3; (-1, 2) даёт -1, 0, 1, 2; (0, -3) даёт 0,
-1, -2, -3.

Твоя функция должна иметь такой прототип:

int	*ft_range(int start, int end);

Тестер вызывает её из своего main: не сдавай свой.
