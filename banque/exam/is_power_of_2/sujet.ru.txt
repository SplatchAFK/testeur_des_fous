Задание             : is_power_of_2
Ожидаемые файлы     : is_power_of_2.c
Разрешённые функции : нет
--------------------------------------------------------------

Напиши функцию, которая возвращает 1, если n является степенью 2, и 0 в
противном случае. 0 не является степенью 2.

Твоя функция должна иметь такой прототип:

int	is_power_of_2(unsigned int n);

Тестер вызывает её из своего main: не сдавай свой.
