Assignment name    : snake_to_camel
Expected files     : snake_to_camel.c
Allowed functions  : malloc, free, realloc, write
--------------------------------------------------------------

Write a program that takes a string written in snake_case and displays it
in lowerCamelCase, followed by a newline.

Each '_' disappears and the letter after it becomes uppercase. The rest is
unchanged.

If the program does not receive exactly one argument, it only displays a
newline.

Examples:

$> ./snake_to_camel "le_testeur_des_fous" | cat -e
leTesteurDesFous$
$> ./snake_to_camel "un_mot_simple" | cat -e
unMotSimple$
$> ./snake_to_camel "deja" | cat -e
deja$
$> ./snake_to_camel | cat -e
$
$>
